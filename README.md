AETHERLIGHT — The Last Lantern: a top-down arena survival shooter. You are Wren, the last Lantern-Keeper, defending the Ember Lantern through 10 waves of shadow glooms — 6 enemy kinds, elites, and two bosses (the Gloom Herald and the Gloom Sovereign) — with WASD movement, mouse aim, dash with i-frames, XP starshards and level-up boon cards. Pure HTML5 canvas + synthesized WebAudio, zero network requests, runs from static files in a desktop browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Or open `game/index.html` directly in a desktop browser. Keyboard + mouse.
